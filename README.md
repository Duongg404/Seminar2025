# Trợ lý phân loại cảm xúc Tiếng Việt

Ứng dụng phân loại cảm xúc (tích cực/trung tính/tiêu cực) cho văn bản tiếng Việt sử dụng mô hình Transformer (PhoBERT).

## 📋 Tính năng chính

- ✅ Phân loại cảm xúc 3 mức: Tích cực (POSITIVE), Trung tính (NEUTRAL), Tiêu cực (NEGATIVE)
- ✅ Xử lý tiếng Việt viết tắt, thiếu dấu (ví dụ: "Rat vui hom nay")
- ✅ Lưu trữ lịch sử phân loại vào SQLite database
- ✅ Giao diện web thân thiện với Streamlit
- ✅ Hiển thị độ tin cậy và thống kê
- ✅ Tự động tải và cache mô hình PhoBERT
